1. How to become a NuN Nexus node

  1. 1
    Open the join form

    Go to nun.nexus/beta. Do not expect a form at apply.nun.nexus/apply in the browser — that host is an API relay (POST only). Opening it now redirects you here to join.

  2. 2
    Declare identity truthfully

    Your X handle (@), optional email, experience, role intent, commitment, and capabilities. Optional public /health probe URL improves resource scoring.

  3. 3
    Submit for investigation

    The form POSTs to the live intake relay (apply.nun.nexus/apply) hosted by Super Node 2. You receive an application ID. No node enters the public ledger until investigation passes.

  4. 4
    Admission & public visibility

    SN2 processes the queue (auto-admit / process_pending), merges by node_hash, integrity-checks, then publishes. Public fields only: type, class, hash, contribution, status, tier path. Full dossiers stay Root-only.

  5. 5
    Find your node_hash & unlock skills

    After admission, open /lookup, confirm the same @handle, and copy your public node_hash. Use that session on /skills to unlock operator mode.

  6. 6
    Progress by contribution

    Path: Observer → Node Operator → Guardian → Architect. Super Node is Root-appointed only. Promotion is contribution-based, not purchase.

3. NuN Skills · using them after you join with your @

After you join with your X handle (@) and are admitted (or while learning as a candidate):

  1. Open the Node Skills catalog and pick a skill band (ops, mesh, ana, …).
  2. Open Grok NuN Node Operator (or the catalog prompt).
  3. In Grok, start a chat and paste the system/skill prompt. Tell Grok your @handle and that you are a NuN Mesh node (or candidate).
  4. Ask Grok to load live truth: https://nun.nexus/status.json and the public ledger.
  5. Use plain commands: /nun-status · /nun-mesh-health · /nun-join-guide · /nun-roadmap · /nun-contribute.
  6. Accept only work in your capability band; report publicly safe results. Never request or paste Root keys.

Skills never unlock ASI trajectory or private dossiers. Root veto remains @bis3946 only.
